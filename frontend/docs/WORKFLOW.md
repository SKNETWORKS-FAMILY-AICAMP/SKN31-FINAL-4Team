# 협업 규칙

둘이서 쓰는 레포다. 규칙은 최소한만 둔다 — 지켜지지 않는 규칙은 없는 게 낫다.

---

## 브랜치

```
main          항상 배포 가능한 상태. 여기 직접 커밋하지 않는다.
 └─ feat/…    기능·화면 작업
 └─ fix/…     버그 수정
 └─ design/…  색·간격·모션 같은 디자인 조정
```

이름은 짧게. `feat/trend-chart-tooltip`, `fix/loading-blank`, `design/salmal-toggle`.

작업 흐름:

```bash
git switch main && git pull          # 항상 최신에서 시작
git switch -c feat/무엇을-하는지
# … 작업 …
git add -A && git commit -m "feat: 트렌드 차트에 호버 툴팁 추가"
git push -u origin feat/무엇을-하는지
# GitHub 에서 PR 열기 → Vercel 이 미리보기 링크를 달아 준다
```

## 커밋 메시지

`타입: 무엇을 했는지` 한 줄. 한국어로 써도 된다.

| 타입 | 언제 |
| --- | --- |
| `feat` | 없던 게 생겼을 때 |
| `fix` | 깨진 걸 고쳤을 때 |
| `design` | 보이는 게 달라졌을 때 (색·간격·모션) |
| `refactor` | 동작은 같은데 코드만 정리 |
| `docs` | 문서만 |
| `chore` | 설정·의존성 |

## PR

- **작게 자주.** 화면 하나, 버그 하나 단위로.
- 제목에 무엇이 달라지는지 쓴다. 스크린샷 한 장이면 리뷰가 훨씬 빨라진다.
- 상대가 리뷰하고 머지한다. 급하면 셀프 머지해도 되지만 PR 은 남긴다 — 나중에 "언제 왜 바뀌었지"를 찾는 유일한 기록이다.
- 머지는 **Squash and merge**. main 히스토리가 PR 단위로 깔끔하게 남는다.

## 담당 구역 — 충돌을 줄이는 방법

파일이 셋으로 갈라져 있으니 이렇게 나누면 같은 화면을 동시에 만져도 거의 안 부딪힌다.

| 파일 | 안에 들어 있는 것 |
| --- | --- |
| `index.html` | 마크업 뼈대. **여기를 고칠 땐 미리 말하기** — 가장 잘 부딪히는 파일이다 |
| `src/styles.css` | 색·간격·타이포·모션 정의 |
| `public/js/app.js` | 데이터·렌더링·애니메이션 로직 |

`styles.css` 와 `app.js` 는 둘 다 크지만, 섹션 주석(`/* ══ 살!말? 챗봇 모드 ══ */`)으로 구역이 나뉘어 있다.
서로 다른 구역을 만지면 깃이 알아서 합쳐 준다.

**동시에 같은 화면을 작업해야 한다면** 한 명은 CSS, 한 명은 JS 로 나눈다.

---

## 충돌이 났을 때

```bash
git switch main && git pull
git switch 내브랜치
git rebase main
# 충돌 파일을 열어 <<<< ==== >>>> 를 정리
git add <파일>
git rebase --continue
```

`styles.css` 충돌은 대부분 양쪽 다 살리면 된다 (서로 다른 규칙을 추가한 것뿐).
`app.js` 충돌은 함수 단위로 보고, 애매하면 되돌리지 말고 상대에게 물어본다.

## 손대기 전에 알아둘 것

이 목업에는 겉보기와 다르게 동작하는 지점이 몇 군데 있다. 지뢰밟기 방지용:

- **anime.js 4.5** 는 3.x 와 API 가 다르다. `ease:'cubicBezier(...)'` 같은 문자열은 안 먹는다. `'out(3)'`, `'inOut(3)'`, `spring()` 을 쓴다.
- **`createDrawable()` 은 엘리먼트가 아니라 프록시를 돌려준다.** 프록시를 애니메이션해야 선이 그려진다. 원본 엘리먼트에 걸면 조용히 아무 일도 안 일어나고 선이 사라진다.
- **숨어 있는 화면을 미리 그리지 않는다.** 등장 애니메이션이 아무도 안 볼 때 끝나 버린다. 뷰 라우터(`goView`)에서 처음 열릴 때 그린다.
- **CSS 애니메이션을 붙였다 뗐다 하면 각도가 0 으로 튄다.** 켜고 끌 땐 `animation-play-state` 로 재우고 깨운다.
- **`display:grid` 는 `[hidden]` 의 기본 `display:none` 을 이긴다.** 숨겨야 하는 grid 요소는 `.x[hidden]{display:none}` 을 따로 써 준다.
- **큰 덩어리를 잘라 붙일 땐 앵커 문자열이 유일한지 먼저 확인한다.** 같은 주석이 CSS 와 JS 양쪽에 있어서 파일 절반이 날아간 적이 있다.
