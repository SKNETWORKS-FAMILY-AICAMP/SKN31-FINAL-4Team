# 개인정보 처리 — 저장 · 통계 비식별 · 탈퇴 삭제

요구사항 PRIVACY-001 을 지금 코드가 어떻게 지키는지 적는다. 코드를 바꾸면 이 문서도 같이 고친다.
(작성 2026-09-27 · 기준 main)

> PRIVACY-001 — 취향·체형·행동 기록·결제 정보 등 민감한 개인정보를 안전하게 다룬다.
> 저장 시 암호화(단방향 해시)하고, 통계 활용 시 비식별 처리하며, 탈퇴 시 30일 내 완전 삭제한다.
>
> ※ 단방향 해시 대상은 **비밀번호**다(2026-09-27 범위 확정).

## 1. 무엇을 저장하나

| 표 | 내용 | 비고 |
|---|---|---|
| `auth_user` | 아이디, 이메일, 비밀번호 | 비밀번호는 Django PBKDF2 단방향 해시 |
| `app.app_user` | 닉네임, 성별, 출생연도, 키·몸무게·체형(`profile_metadata`) | 평문 |
| `app.user_taste` | 즐겨입는 스타일 | 평문 |
| `app.user_event` · `app.user_daily_activity` | 검색·조회·투표·찜·챗봇 질문 기록, 접속일·체류 시간 | 금주의 리포트 · 경험치 계산 |
| `app.chat_session` | 로그인 사용자의 챗봇 대화 | 본인만 조회 |
| `app.vote_*` · `app.site_feedback` | 살!말? 카드·표·댓글·신고, 홈페이지 피드백 | |

결제 정보는 저장하지 않는다. 요금제 화면만 있고 결제 연동이 없다.
이메일 인증번호는 서버 세션에 `salted_hmac` 해시로만 둔다(`apps/api/email_verify.py`).

## 2. 저장 시 보호

- **비밀번호** — Django 기본 PBKDF2(단방향 해시). 원문은 어디에도 남지 않는다.
- **세션 쿠키** — HttpOnly. HTTPS 전환 뒤 Secure·HSTS 를 켠다(`config/settings.py` 쿠키 보안 주석).
- **서버 비밀값** — `.env` 와 Vercel 환경변수에만 둔다. 저장소에는 `.env.example` 자리표시자뿐이다.
- **단방향 해시는 비밀번호에만 적용한다** (2026-09-27 요구사항 범위 확정).
  취향·체형은 화면에 다시 보여 주고 추천에 써야 하는 값이라 해시하지 않는다.
  이 값들은 RDS 저장소 암호화(AWS 콘솔의 RDS 'Encryption' 설정)와 DB 접근 통제(운영 계정 · 사설망)로 보호한다.

## 3. 통계 활용 시 비식별

회원 한 사람을 가리키는 값(아이디 · 닉네임 · 이메일)은 **여러 사람을 모은 통계에 넣지 않는다.**

| 쓰는 곳 | 무엇을 쓰나 | 비식별 방식 |
|---|---|---|
| 트렌드 지표(`term_metric_daily` 등), 챗봇 지표 답변 | 공개 쇼핑몰·유튜브·검색량 수집 데이터 | 회원 데이터를 쓰지 않는다 |
| 살!말? 투표 결과 | `vote_ballot` | 표 수·비율만 보인다. 누가 어느 쪽에 투표했는지는 화면·API 어디에도 없다 |
| 챗봇 답변 피드백 · 용어 등록 요청 (`ChatBot/data/*.jsonl`) | 질문 앞 300자, 의도, 사유 | 회원 id · 닉네임을 적지 않는다(`ChatBot/server.py _feedback`) |
| 운영 대시보드 집계 | 건수 | 사람 단위 목록은 운영 계정(is_staff)만 연다 |
| 금주의 리포트 · 취향 브리핑 · 경험치 | 그 사람 자신의 기록 | 본인에게만 보인다(다른 사람과 합치지 않는다) |

공개되는 것은 사용자가 스스로 올린 것뿐이다 — 살!말? 카드와 댓글에는 닉네임이 붙는다.

## 4. 탈퇴 시 삭제

`POST /api/auth/withdraw` (`apps/api/auth_views.py withdraw`) 는 **30일을 기다리지 않고 즉시** 지운다.

- `auth_user` 를 지우면 `app_user` 와 그 아래 기록이 모두 함께 지워진다(FK `on_delete=CASCADE`):
  취향, 행동 기록, 찜, 살!말? 카드 · 표 · 댓글 · 피드백, 챗봇 대화, 알림, 알림 설정, 용어 요청, 접속 · 경험치, 홈페이지 피드백.
- 남는 것은 **다른 사람의 기록**뿐이고, 거기서 이 사람을 가리키는 값을 비운다.
  - 이 사람이 한 신고(`vote_report.reporter`) → 신고자만 비운다(`SET_NULL`). 신고 내용은 운영 검토용으로 남는다.
  - 이 사람의 글에 들어온 신고의 대상 사본(`vote_report.target_snapshot` 의 글쓴이 id · 댓글 원문)
    → `{"withdrawn": true}` 로 지운다(2026-09-27 추가, `apps/api/test_withdraw_privacy.py`).
- ⚠️ **백업** — RDS 자동 백업 · 스냅숏에는 보존 기간 동안 남는다.
  '30일 내 완전 삭제' 를 지키려면 RDS 자동 백업 보존 기간을 **30일 이하**로 두고, 수동 스냅숏을 30일 넘게 보관하지 않는다.
  **→ 담당자가 AWS 콘솔(RDS › 데이터베이스 › 유지 관리 및 백업 › 백업 보존 기간)에서 확인한다.**

python manage.py test apps.api.test_withdraw_privacy   # 탈퇴 삭제 · 신고 사본 정리
