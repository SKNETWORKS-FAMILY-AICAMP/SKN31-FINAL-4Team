# 브랜드 backfill

브랜드 소스에서 미매핑된 애들에 대해서 정보 추가 수집 
```
python python collection\zigzag\zigzag_store_profile_backfill.py `
  --only-unmapped `
  --missing-only
  ```
  
결과 확인하고 마음에 들면 
db로 올려버리기 ㅋ 
```
python collection\zigzag\zigzag_store_profile_backfill.py `
  --only-unmapped `
  --missing-only `
  --update-db
  ```
